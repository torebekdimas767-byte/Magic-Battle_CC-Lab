# Magic Battle · CC LAB

Браузерная AR-игра, в которой тело игрока становится контроллером. MediaPipe распознаёт позы, кисти, удары и уклонения, а Three.js рисует магические эффекты поверх камеры.

## Что внутри

- сюжетная кампания из 5 глав с двумя финалами;
- 16 заклинаний, 4 боксёрских удара и система комбо;
- адаптивное сглаживание скелета и защита от случайного сброса жеста;
- отдельное распознавание кистей, калибровка и индикатор качества захвата;
- демо-режим без камеры;
- подключение камеры телефона через `phone-cam-cc-lab.html`;
- **две дополнительные мини-игры** (см. ниже): `shadow-racer.html` и `rune-shooter.html`;
- автоматическая публикация на GitHub Pages.

## Структура проекта

| Файл | Что это |
|---|---|
| `index.html` | Основная игра Magic Battle, главное меню и раздел «Доп игры» |
| `phone-cam-cc-lab.html` | Страница для подключения камеры телефона (PeerJS) |
| `shadow-racer.html` | Мини-игра «Теневая гонка» — управление двумя руками |
| `rune-shooter.html` | Мини-игра «Рунный рубеж» — стрельба пальцем |
| `.github/workflows/pages.yml` | Автодеплой на GitHub Pages при пуше в `main` |

Каждая мини-игра — один самодостаточный HTML-файл (HTML + CSS + JS внутри), сборка не нужна. Из каждой игры есть кнопка «← MAGIC BATTLE», которая ведёт обратно на `index.html`, поэтому все файлы должны лежать в одной папке (в корне репозитория).

## Дополнительные игры

Обе игры используют камеру и модель **MediaPipe Hands** (21 точка на каждой кисти, до 2 рук). Изображение с камеры отзеркалено, как в зеркале. У обеих есть запасной режим без камеры.

### 🏎 Теневая гонка (`shadow-racer.html`)

Гонка, где рулём служат твои руки.

**Как играть**
1. Нажми «Играть с камерой» и разреши доступ к камере.
2. Покажи камере две руки на ширине плеч, будто держишь руль.
3. Наклоняй воображаемый руль влево или вправо — машина смещается по трассе.
4. Объезжай чужие машины и проезжай через световые ворота.

**Как это работает**
- Для каждой руки считается центр ладони — среднее по точкам запястья и оснований пальцев (0, 5, 9, 13, 17).
- Берутся самая левая и самая правая рука, и считается угол линии между ними (`atan2`). Угол делится на 0,62 рад и ограничивается диапазоном −1…1 — это и есть «руль».
- Руль плавно сглаживается, затем сдвигает машину по поперечной оси. Подсказка внизу показывает «Прямо», «Влево» или «Вправо».
- Трасса нарисована в псевдо-3D на canvas: объекты появляются у горизонта и растут по мере приближения.
- Игровые правила: 3 единицы прочности (♥). Столкновение с машиной отнимает одну и трясёт экран. Световые ворота дают +100 м. Скорость растёт вместе с дистанцией. Заезд заканчивается, когда прочность заканчивается; итог — пройденные метры.
- **Без камеры:** кнопка «Клавиатура ← →».

### ✦ Рунный рубеж (`rune-shooter.html`)

Аркадный 2D-шутер «от первого лица»: тени приближаются к цитадели, а ты сбиваешь их пальцем.

**Как играть**
1. Вытяни указательный палец — прицел следует за кончиком пальца.
2. Коснись большим пальцем указательного (щипок) — это выстрел.
3. Не дай теням дойти до тебя: три прорыва завершают раунд.

**Как это работает**
- Позиция прицела — кончик указательного пальца (точка 8), переведённая в координаты экрана с учётом зеркала и обрезки видео; движение сглаживается.
- Выстрел срабатывает в момент щипка: расстояние между кончиком большого (4) и указательного (8) пальцев становится меньше 35% ширины ладони. Условие «только на смену состояния» не даёт очереди из одного щипка.
- Попадание считается по расстоянию от прицела до тени с учётом её размера и удалённости.
- Тени растут и приближаются; чем ближе, тем крупнее цель. Обычная тень гибнет с одного попадания (+100 очков), броня из волны 4 и выше требует двух (+25 за пробитие).
- Волна повышается каждые 700 очков: тени появляются чаще и двигаются быстрее.
- **Без камеры:** кнопка «Мышь + клик» — целься мышью, стреляй кликом.

### Приватность

В обеих играх жест «средний палец» размывает эту кисть на экране (квадратной областью), и такая рука не используется для управления. Видео обрабатывается локально в браузере и никуда не отправляется.



### 📱 Камера телефона (`phone-cam-cc-lab.html`)

Это отдельная веб-страница, которая превращает телефон в удалённую камеру для Magic Battle. Она передаёт видеопоток с телефона на компьютер, где запущена игра. Это удобно, если компьютерная камера не подходит или нужно поставить телефон на расстоянии.

**Как подключить**
1. Опубликуй проект на GitHub Pages или открой страницу по HTTPS. Доступ к камере телефона в браузере требует защищённого соединения (HTTPS; для локальной разработки также подходит localhost).
2. На компьютере открой Magic Battle и выбери режим подключения камеры телефона. Игра должна показать четырёхзначный код подключения.
3. На телефоне открой страницу `phone-cam-cc-lab.html` по адресу сайта, например `https://<имя-пользователя>.github.io/Magic-Battle_CC-Lab/phone-cam-cc-lab.html`.
4. Разреши браузеру доступ к камере. Выбери заднюю или фронтальную камеру, введи код с экрана игры и нажми «Подключиться».
5. Поставь телефон горизонтально примерно в 2–3 метрах от себя. Не блокируй экран, пока идёт передача.

**Важно:** телефон и компьютер должны иметь доступ к интернету. Если камера не запускается, проверь разрешение браузера и используй HTTPS. Код должен совпадать с кодом, показанным в игре. Передача видео выполняется через PeerJS.

## Запуск

Камера браузера работает только на `localhost` или через HTTPS. Для локальной проверки запустите любой статический сервер в папке проекта, например:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000/index.html`. На GitHub Pages всё работает по HTTPS без дополнительной настройки.

Мини-игры открываются из главного меню или напрямую: `/shadow-racer.html` и `/rune-shooter.html`.

На первом экране основной игры нажмите «Проверить камеру». Хороший результат калибровки — от 62%. Встаньте по центру, покажите обе кисти и добавьте света перед собой. Для мини-игр достаточно хорошего освещения и видимых рук.

Нужен интернет: модель MediaPipe Hands загружается с CDN jsDelivr.

## Технологии

HTML, CSS, JavaScript, MediaPipe Pose + Hands, Three.js и PeerJS. Сборка не требуется.
